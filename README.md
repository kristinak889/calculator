# Семейный бюджет

Сайт для учёта домашнего бюджета: доходы, расходы, финансовая цель и список покупок. Данные хранятся только в браузере (LocalStorage), сервер и регистрация не нужны.

## Страницы

- [index.html](index.html) — приветственная страница
- [app.html](app.html) — само приложение (бюджет и список покупок)

Старый файл `Калькулятор.html` перенаправляет в приложение, чтобы не ломать привычную ссылку.

## Как открыть

Откройте `index.html` в браузере. Если браузер ограничивает LocalStorage для файлов с диска, запустите локальный сервер из папки проекта, например:

```bash
python -m http.server 8080
```

Затем перейдите по адресу `http://localhost:8080`.

## Возможности

- учёт доходов и расходов по категориям
- остаток, доля свободных средств и оценка бюджета
- расчёт ежемесячных накоплений на цель
- список покупок с количеством, ценой и отметкой «куплено»

Ключи LocalStorage:

- `familyBudgetTransactions` — операции бюджета
- `familyBudgetShopping` — список покупок
